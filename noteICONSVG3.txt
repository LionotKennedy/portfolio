# Solution: Création d'un composant SVG unifié avec données externes

Je vais vous aider à créer un système où tous les SVG sont gérés dans un fichier de données séparé et importés dans un composant unique.

## Étape 1: Création du fichier de données SVG

Créez un fichier `svgData.ts` (ou `.js`) qui contiendra tous vos SVG:

## Étape 2: Création du composant SVG unifié

Créez un composant `SvgDisplay.tsx` qui gérera l'affichage de tous vos SVG:

```typescript
// components/SvgDisplay.tsx
import React from 'react';
import Link from 'next/link';
import { svgData } from '../data/svgData';

interface SvgDisplayProps {
  type: 'topLangs' | 'stats' | 'skillIcons' | 'streak' | 'pin';
  className?: string;
  link?: string;
  alt: string;
}

const SvgDisplay: React.FC<SvgDisplayProps> = ({ 
  type, 
  className = "", 
  link, 
  alt 
}) => {
  // Déterminer la source en fonction du type
  let src = "";
  
  switch(type) {
    case 'topLangs':
      src = svgData.githubStats.topLangs;
      break;
    case 'stats':
      src = svgData.githubStats.stats;
      break;
    case 'skillIcons':
      src = svgData.skillIcons;
      break;
    case 'streak':
      src = svgData.githubStreak;
      break;
    case 'pin':
      src = svgData.githubStats.pin;
      break;
    default:
      src = "";
  }

  // Créer l'élément image
  const imageElement = (
    <img
      className={`w-full h-auto ${className}`}
      src={src}
      alt={alt}
      loading="lazy"
    />
  );

  // Si un lien est fourni, envelopper l'image avec le lien
  if (link) {
    return (
      <Link href={link} target="_blank" className="w-full">
        {imageElement}
      </Link>
    );
  }

  return imageElement;
};

export default SvgDisplay;
```

## Avantages de cette approche

1. **Centralisation**: Toutes les données SVG sont gérées dans un seul fichier
2. **Maintenabilité**: Modifiez les URLs une seule fois si nécessaire
3. **Typage fort**: TypeScript assure la cohérence des types
4. **Évolutivité**: Facile à étendre avec de nouveaux SVG
5. **Lisibilité**: Le composant principal est plus propre et compréhensible

## Pour les SVG locaux

Si vous avez des SVG locaux, vous pouvez étendre la solution:

1. Ajoutez-les au fichier `svgData.ts`
2. Étendez le type `SvgDisplayProps` pour inclure ces nouveaux types
3. Ajoutez les cas dans le switch statement du composant `SvgDisplay`

Cette approche vous permet de gérer efficacement tous vos SVG, qu'ils soient distants ou locaux.
