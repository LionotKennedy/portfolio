Objectif  
- Un seul composant `<SvgDisplay />`  
- Une source de vérité `svgData.ts` : tableau d’objets (id, url ou tableau d’urls, type, alt, cols, etc.)  
- Chaque `ItemLayout` n’affiche **qu’une ligne** :  

```tsx
<ItemLayout className={svg.cols}>
  <SvgDisplay data={svg} />
</ItemLayout>
```

2. Composant unique – `components/SvgDisplay.tsx`  
```tsx
"use client";
import Link from "next/link";
import Image from "next/image";

type Props = { data: import("@/data/svgData").SvgPack };

const SvgDisplay: React.FC<Props> = ({ data }) => {
  /* -------- multi-icons (skillicons) -------- */
  if (data.type === "multi") {
    const url = `https://skillicons.dev/icons?i=${(data.src as string[]).join(",")}`;
    return (
      <div className="w-full h-auto">
        <Image
          src={url}
          alt={data.alt}
          width={1200}   // largeur fictive – aspect-ratio conservé
          height={200}
          className="w-full h-auto"
          loading="lazy"
        />
      </div>
    );
  }

  /* -------- single SVG -------- */
  const content = (
    <Image
      src={data.src as string}
      alt={data.alt}
      width={800}
      height={400}
      className="w-full h-auto"
      loading="lazy"
    />
  );

  return data.link ? (
    <Link href={data.link} target={data.target} className="block w-full">
      {content}
    </Link>
  ) : (
    content
  );
};

export default SvgDisplay;
```


4. SVG locaux  
Si un jour tu ranges les icônes dans `public/icons/xxx.svg`, remplace simplement la propriété `src` :

```ts
src: "/icons/logo.svg"
```

Le composant `<Image>` se charge du reste.

Résultat :  
- Un seul fichier de données pour toutes les images  
- Un seul composant d’affichage  
- Responsive, lazy-loaded, et prêt pour du SVG local ou distant.
